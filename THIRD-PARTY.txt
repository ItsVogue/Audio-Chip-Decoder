Sound-chip tables and behaviour
-------------------------------
The decoders for the NEC uPD7759, the OKI MSM6295 phrase table, CVSD delta
modulation and TI LPC speech were written for this app. The constants stored
inside those chips (the uPD7759 step table and the TI speech-chip energy,
pitch, filter and chirp tables in audiochip\lpc_tables.py) and the description
of how the chips behave come from the MAME project:
  src/devices/sound/upd7759.cpp, tms5220.cpp, tms5110r.hxx, hc55516.cpp
  https://github.com/mamedev/mame

Programmer protocols
--------------------
No code was copied for these; the commands each device understands were taken
from the following published descriptions.
CH341A, CH347     WCH's library headers CH341DLL_EN.H and CH347DLL_EN.H
CH341A over USB   the command set documented in flashrom's ch341a_spi.c
serprog           flashrom's serprog protocol specification
FT232H            FTDI application note AN_108 (MPSSE command processor)
