Sound-chip tables and behaviour
-------------------------------
The decoders for the NEC uPD7759, the OKI MSM6295 phrase table, CVSD delta
modulation and TI LPC speech were written for this app. The constants stored
inside those chips (the uPD7759 step table and the TI speech-chip energy,
pitch, filter and chirp tables in audiochip\lpc_tables.py) and the description
of how the chips behave come from the MAME project:
  src/devices/sound/upd7759.cpp, tms5220.cpp, tms5110r.hxx, hc55516.cpp

Console and arcade formats added in 0.6.0
-----------------------------------------
The decoders for SNES BRR, Yamaha ADPCM-A and Nintendo DSP ADPCM were written
for this app from the published behaviour of those chips. Their output was
compared, sample for sample, with these projects' own code, which is not
included in the app:
  SNES BRR         blargg's SPC_DSP as shipped in Snes9x (LGPL 2.1)
                   https://github.com/snes9xgit/snes9x
  Yamaha ADPCM-A   ymfm by Aaron Giles (BSD 3-Clause); the step table is the
                   one in the chip, also listed in MAME
                   https://github.com/aaronsgiles/ymfm
  Nintendo DSP     vgmstream (ISC)   https://github.com/vgmstream/vgmstream
The .dsp header checks follow vgmstream's. tests\data\reference holds inputs
and the reference outputs they produced.

Test files
----------
tests\data\ff\sample_nb.amr and sample_wb.amr come from the test assets of
the Android media library (androidx/media), Apache License 2.0.
https://github.com/androidx/media
tone.spx and tone_wb.spx were made with libspeex (BSD); the other files in
that folder were made with FFmpeg's encoders. None of them ship with the
installed app.

Programmer protocols
--------------------
No code was copied for these; the commands each device understands were taken
from the following published descriptions.
CH341A, CH347     WCH's library headers CH341DLL_EN.H and CH347DLL_EN.H
CH341A over USB   the command set documented in flashrom's ch341a_spi.c
serprog           flashrom's serprog protocol specification
FT232H            FTDI application notes AN_108 (MPSSE command processor)
                  and AN_113 (I2C through MPSSE)
