# Audio Chip Decoder

Reads a memory chip, finds the audio stored on it, and exports audio files. Windows.

## Download

**[Get the latest installer](https://github.com/ItsVogue/Audio-Chip-Decoder/releases/latest)**: on that page, under **Assets**, click `AudioChipDecoder-Setup-x.y.z.exe` and run it.

One file, no Python needed, installs for your user only. Windows SmartScreen may warn because the installer is not code-signed: choose "More info", then "Run anyway".

The installer is not in the list of files above. GitHub keeps downloads on the **Releases** page (right-hand side of this page), which is where the link goes.
